> mock 範例：demo-cli 是虛構工具，用來示範 reference 型記憶的寫法。

1. 設定檔裡的路徑寫 `~` 不會展開，要寫成絕對路徑或用工具提供的變數；寫錯時工具不報錯，只是讀不到檔。
2. 同名設定同時出現在全域與專案層時，專案層整段覆蓋全域層，不是逐鍵合併。

**驗證方式**：改完執行 `demo-cli config --print-effective`，看實際生效的值；不要只看設定檔本身。

**何時重查**：demo-cli 升大版本後，上面兩條都要重新實測一次。

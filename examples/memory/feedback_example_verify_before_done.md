> mock 範例：格式照真實的 feedback 記憶寫，事件與日期都是虛構的。

回報完成時，同一句附上跑過的指令與看到的輸出，不只寫「應該可以了」。

**Why:** 2026-01-12 一次範例情境：agent 說「測試都過了」，實際只跑了語法檢查，沒跑單元測試；使用者照著合併後才發現一支測試是紅的。

**How to apply:**
- 說「完成／修好了」→ 同句附指令＋輸出摘要。
- 只做了部分驗證 → 寫「只驗了 X，未驗證 Y」，不要用「應該」帶過。
- 沒改程式碼就不重跑同一個指令；要更強的證據就換一個驗證角度。
